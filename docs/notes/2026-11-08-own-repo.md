# asXii gets its own repo

**Decided (Greg, 2026-11-08):** asXii moves out of neon-1 (`ascii-editor/`) into github.com/gschomburg/asxii.

- The files were copied as they were at neon-1 commit `9d1cba4d` (v0.149). The history stays in neon-1.
- The neon-1 copy was left in place.
- Changes made during the move:
  - The topic docs moved into `docs/`.
  - `node ascii-editor/x.js` became `node x.js`.
  - The links to neon-1 docs now point at GitHub.
  - The convention files were added.
- `dist/` stays the hand-edited web root, and the build scripts stay at the root. Moving to web.md's
  `public/` + `tools/` layout would be a separate change, if wanted.
